# SmartGeoAI
## AI Address Parsing and Location Intelligence System


## Problem

Indian delivery addresses are often messy and unstructured.
Landmark directions, incorrect pincodes, informal locality names,
and spelling variations create last-mile delivery problems.


## Solution

SmartGeoAI converts a messy Indian address into an accurate
geocoded location using:

- AI Address Parsing
- Address Normalization
- Pincode Validation
- OpenStreetMap Geocoding
- Landmark Verification
- Confidence Scoring


## Architecture


User Address

↓

AI Address Parser

↓

Address Normalizer

↓

Pincode Validation

↓

OpenStreetMap Services

↓

Landmark Evidence

↓

Confidence Engine

↓

Map Result



## Features

✅ Parses messy Indian addresses

✅ Extracts landmark, city, state and pincode

✅ Validates pincode information

✅ Uses OpenStreetMap for geolocation

✅ Finds nearby landmarks

✅ Provides confidence score

✅ Shows evidence behind prediction

✅ Displays final location on map
